# Laboratorio #5


## Algoritmos de Ordenamiento 

En la laboratorio #5 se comparte un código en el cuál se utilizan los tipos de algoritmos de ordenamiento , se puede denotar los diferentes comportamientos en sus complejidades. Se notan `Bubble Sort`(O(n^2)) en el peor caso.) , `Selection Sort`((O(n^2))),`Insertion Sort`((O(n^2))),`Quick Sort`((O(n \log n)) en el mejor caso; (O(n^2))) 



## Se compila y se ejecuta

Programa #1: Está conformado por Implementacion.hpp  como header luego el main.cpp .

Implementacion.hpp contiene las funciones de los recorridos según los tipos de algorimo de ordenamiento guardados en los vectores.
.

main.cpp : Es el principal donde se está el menú principal y se llaman las funciones respectivas



```bash
  g++ .\src\main.cpp .\src\Implementacion.hpp -o .\build\main.exe
 
  .\build\main.exe

```
