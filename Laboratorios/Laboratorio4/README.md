# Laboratorio 4


## Estructuras de Datos y algoritmos

En la laboratorio #4 se muestran dos ejemplos de programaciones , el primero sobre listas enlazadas con nodos y el segundo sobre árboles 



## Se compila y se ejecuta

Programa #1: Está conformado por ListaEnlazada.hpp y Nodo.hpp como headers luego el main.cpp .

Nodo.hpp contiene el struct nodo el cual posee un constructor donde sus atributos son públicos y su clase por default privada.

ListaEnlazada.hpp : Contiene funciones del programa en el que como buscar,eliminar,imprimir,insertar inicio, insertar final, destructor.

main.cpp : Es el principal donde se está el menú principal y se llaman las funciones respectivas



```bash
 g++ ListaEnlazada.hpp Nodo.hpp  main.cpp  -o Nodos.exe
 
 .\Nodos.exe

```
    
Programa #2:  Está conformado por ArbolBinarioBusqueda.hpp y NodoArbol.hpp como headers luego el main.cpp .

NodoArbol.hpp contiene el struct nodo el cual posee un constructor y los punteros de NodoArbol izquierdo y derecho.

ArbolBinarioBusqueda.hpp : Contiene funciones del programa en el que como incertar,preOrden,inOrden,postOrden, buscar,estaBalanceado,altura.

main.cpp : Es el principal donde se está el menú principal y se llaman las funciones respectivas

```bash
 g++ .\ArbolBinarioBusqueda.hpp  NodoArbol.hpp  main.cpp  -o NodosArboles.exe
 
 .\NodosArboles.exe

```
